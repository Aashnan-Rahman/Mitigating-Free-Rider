# Historical v8 evidence

- `organized/` contains historical experiment records grouped for analysis.
- `_archive_extract/` preserves extracted source records used during organization.

These are data for earlier papers, including the v8 behavior analysis. They are
not the live experiment queue. Their paths are retained because
`build_paper_v4_v8_statistics.py` reads `organized/` directly.

For current writing, use the [v7.2 paper](../paper_version_staging/versions/v07_2_review_revision/README.md).
For previous papers, use the [paper version index](../paper_version_staging/versions/README.md).
