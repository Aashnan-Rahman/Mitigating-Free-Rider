\section{Audit-Clock Trace Check}\label{app:audit-clock}
The frozen engine restarts the quiet clock when the raw finding set
$\mathcal F$ is empty. Audit enrollment instead uses
$\mathcal F_{\rm elig}=\mathcal F\setminus\mathcal D$, where $\mathcal D$
is the pre-decrement cooldown set. If all findings are in cooldown,
the raw guard can unset the clock without opening review and thereby
prevent later audits. The corrected review engine restarts the clock
when no actual review or probation requires paired coverage.

The guards agree on all 622 recorded audits in the 96-run study.
There are 609 empty-finding audits. In each of the other 13, the raw
finding count exceeds the number of active clients in cooldown, proving
that at least one finding remains eligible. This is a trace agreement
check, not equivalence for unobserved cooldown states. The primary
training results were not relabeled or recomputed. Prospective honest-only
and low-prevalence runs use the corrected guard and an independent
registered source manifest.

\section{Reproducibility and Scope of the New Diagnostic}
The norm-matching export contains 72 round-20 FR2--FR4 cases. The analysis
first reproduces every stored statistical certificate with the unchanged
decision backend. It then replaces only attacker norms by the same-trap
median honest norm while preserving the normalized tensor profile.
Evaluation labels construct this oracle input; the detector receives no
labels. This tests feature sensitivity under additional attacker
information, not a complete attack execution or confirmed removal.
The full per-case counts, completed-run inventory, queue snapshot and
input hashes are in \path{generated/revision/}.
