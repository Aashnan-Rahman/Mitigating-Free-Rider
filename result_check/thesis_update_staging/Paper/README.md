# SWT-CP paper

This directory contains an IEEE conference-style paper distilled from the thesis report in `../Free Rider/`.

Build it with:

```powershell
latexmk -pdf paper.tex
```

The thesis currently has no experimental results. Accordingly, the manuscript presents SWT-CP as a proposed, testable method and includes an evaluation protocol rather than fabricated result tables. Once experiments are complete, add the measured results before submission.
