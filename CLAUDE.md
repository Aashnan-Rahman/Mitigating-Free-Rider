## Project

Federated-learning free-rider detection research. The detector (code name
`swtcp_v15_4`) is written up as **SPARC-FL** (Statistical Peer Auditing with
Repeated Confirmation); the previous paper name was BaitFL. Python/PyTorch
simulator, MNIST and CIFAR-10, 100 clients, 100 rounds, attacks FR1–FR4.

## Rules for paper and results work

- Report only completed runs in the paper. No in-progress or queue language.
- Never pool results from different detector versions.
- Never retune detector rules or thresholds to get a desired removal count.
  Ground-truth labels are for evaluation only.
- Don't claim SPARC-FL beats other detectors in a matched benchmark. The claim is
  near-complete removal at ≥10% prevalence using only returned models, at
  measured server cost below 1 s/round at N = 100.
- Keep the same terminology as v7.4: "slot"/"challenge dispatch", not "trap".
- Don't modify source-hashed/registered experiment files (registrations, frozen
  plans, `train_v15_4.py`, detector modules). A change makes checkpoint resume
  fail and invalidates the registration.
