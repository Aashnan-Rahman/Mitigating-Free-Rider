# Free-rider attack illustration

Three devices train the received model using private local data. A fourth
device skips training and returns a fabricated, perturbed response. Data and
processor icons distinguish available training resources from absent ones.
The battery icon is removed. Free riding may also be a
choice despite available resources. The server does not receive these local
statuses. Noise fabrication is an example, not a definition of every attack.

The source is editable TikZ. The PDF and SVG are vector outputs and the PNG
is a preview. A thin outer border frames the figure. The manuscript keeps its
own source/PDF copies under `figures/`.
